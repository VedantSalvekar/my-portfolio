# Vedant's Portfolio

Hi, I'm Vedant — a software engineer who also loves painting. This is where I share the projects I've built, my work experience, and some of my artwork.

[Visit my portfolio](https://VedantSalvekar.github.io/my-portfolio/)

## What's here

- My work experience and projects.
- A gallery of my paintings.
- Recent GitHub commits and LeetCode activity.
- My CV and links to get in touch.

Built with React, Vite, Tailwind CSS, and Framer Motion.

## Run it locally

Clone this repo, open the project folder, and run:

```bash
npm install
npm run dev
```

Open the local URL printed in your terminal.

To build and preview the production version:

```bash
npm run build
npm run preview
```
